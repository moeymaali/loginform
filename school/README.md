### Beschrijving van het project

Voor dit project maak ik een loginformulier met HTML en CSS. Het formulier heeft een veld voor een e-mailadres en een wachtwoord. Ook komen er een inlogknop, een optie om ingelogd te blijven en een link voor een vergeten wachtwoord.

HTML gebruik ik voor de structuur van het formulier. CSS gebruik ik voor de kleuren, opmaak en effecten.

### Waarom wil ik dit project maken?

Ik wil leren hoe ik een modern en duidelijk loginformulier maak. Ik wil ook beter leren werken met HTML-formulieren en CSS. Deze kennis kan ik later gebruiken voor grotere websites.

### Randvoorwaarden

Het project wordt gemaakt met HTML en CSS.
Het formulier moet een e-mailveld hebben.
Het formulier moet een wachtwoordveld hebben.
Er moet een inlogknop aanwezig zijn.
Verplichte velden worden gecontroleerd door HTML.
Het ontwerp moet duidelijk en gebruiksvriendelijk zijn.
Het formulier moet werken op een computer en telefoon.
Ik gebruik geen echte persoonsgegevens.
Wachtwoorden worden niet opgeslagen.
Ik gebruik alleen afbeeldingen en lettertypen die ik mag gebruiken.
Ik houd rekening met AVG, auteursrecht en licenties.
Met alleen HTML en CSS controleert het formulier geen echte accounts.
