### Beschrijving van het project

Bij mijn vorige opdracht heb ik een loginpagina gemaakt met HTML en CSS.

Nu ga ik verder met mijn website. Ik ga een homepagina, registerpagina en forgot password pagina maken.

Als je op Login klikt, ga je naar de homepagina.  
Als je op Register klikt, ga je naar de registerpagina.  
Als je op Forgot Password klikt, ga je naar de pagina voor vergeten wachtwoord.

Mijn homepagina wordt een website voor Susu Horizon Travel.

Ik ga HTML, CSS en JavaScript gebruiken.

HTML gebruik ik voor de structuur van de website.  
CSS gebruik ik voor het design.  
JavaScript gebruik ik om de website interactief te maken en om invoervelden te controleren.

### Waarom wil ik dit project maken?

Ik wil leren hoe ik meerdere pagina's kan maken en met elkaar kan verbinden.

Ik wil ook meer leren over JavaScript en hoe ik HTML, CSS en JavaScript samen kan gebruiken.
