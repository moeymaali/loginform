# README4 – Susu Horizon Travel

## 1. Projectnaam
Susu Horizon Travel Select Room & Dates.

## 2. Beschrijving
Susu Horizon Travel is een reiswebsite die ik maak voor mijn opleiding Software Developer.

Op mijn website kunnen gebruikers verschillende bestemmingen en hotels bekijken.

Ik heb vier bestemmingen:
- Dubai
- Somalië
- Koerdistan
- Malediven

Ik werk nu ook aan een nieuwe pagina: **Select Room & Dates**.

## 3. Nieuwe functie – Select Room & Dates
Op deze pagina kan de gebruiker:

- Een hotelkamer kiezen.
- Een check-in datum kiezen.
- Een check-out datum kiezen.
- Het aantal gasten selecteren.
- De totale prijs berekenen.

Er zijn drie soorten kamers:
- Standard Room – €90 per nacht
- Deluxe Room – €150 per nacht
- Luxury Suite – €250 per nacht

JavaScript berekent de prijs op basis van de kamer en het aantal nachten.

Dit is een oefenproject. Gebruikers kunnen nog geen echte hotelreservering maken.

## 4. Gebruikte technieken

**HTML**
Ik gebruik HTML voor de structuur van mijn website, zoals knoppen, afbeeldingen en invoervelden.

**CSS**
Ik gebruik CSS voor de kleuren, de indeling en het ontwerp van mijn website.

**JavaScript**
Ik gebruik JavaScript om de zoekfunctie, filters en prijsberekening te laten werken.
