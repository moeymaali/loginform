# RETRO4 – Susu Horizon Travel

## 1. Projectnaam
Susu Horizon Travel – Select Room & Dates

## 2. Wat heb ik gemaakt?
Tijdens deze sprint heb ik gewerkt aan mijn reiswebsite Susu Horizon Travel.

Ik heb een hotelpagina gemaakt waar gebruikers verschillende hotels kunnen bekijken. Ook heb ik gewerkt aan een boekingspagina waar gebruikers een kamer, check-in datum, check-out datum en aantal gasten kunnen kiezen.

JavaScript berekent de totale prijs op basis van de gekozen kamer en het aantal nachten.

## 3. Wat ging goed?
- Ik heb mijn hotelpagina verder verbeterd.
- Ik heb hotelkaarten gemaakt met foto's, namen en prijzen.
- Ik heb de View Hotel knoppen gekoppeld aan hotelpagina's.
- Ik heb JavaScript gebruikt om hotelprijzen te berekenen.
- Ik heb geleerd hoe ik datums kan controleren.
- Ik heb CSS Grid en Flexbox gebruikt voor mijn ontwerp.

## 4. Wat ging minder goed?
- Sommige knoppen werkten in het begin niet.
- Ik had fouten in mijn JavaScript-code.
- Soms gebruikte ik een verkeerde ID tussen HTML en JavaScript.
- Het berekenen van prijzen en controleren van datums vond ik moeilijk.

## 5. Hoe heb ik de problemen opgelost?
Ik heb mijn HTML en JavaScript stap voor stap gecontroleerd.
Ik heb Chatgbt gevraagd design idee.
Ik heb gekeken of de ID's hetzelfde waren en of mijn bestanden goed gekoppeld waren.
Daarna heb ik mijn website opnieuw getest om te kijken of de knoppen en functies werkten.

## 6. Wat heb ik geleerd?
Ik heb geleerd hoe ik:

- HTML gebruik voor de structuur.
- CSS gebruik voor het ontwerp.
- JavaScript gebruik om mijn website interactief te maken.
- De totale hotelprijs bereken.
- Fouten in mijn code kan vinden en oplossen.

## 7. Wat wil ik volgende keer verbeteren?
Ik wil alle hotels een eigen boekingspagina geven.

Ook wil ik een bevestigingspagina maken waar gebruikers hun gekozen kamer, datums en totale prijs kunnen bekijken.

Daarnaast wil ik JavaScript beter begrijpen, zodat ik meer code zelfstandig kan schrijven.

## 8. Conclusie
Ik ben tevreden met mijn vooruitgang tijdens deze sprint. Niet alles ging meteen goed, maar ik heb veel geleerd door fouten te maken en deze op te lossen.

Ik wil blijven oefenen met HTML, CSS en JavaScript om mijn website steeds beter te maken.
